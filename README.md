# Penguin - NewerSMBW Fork
This is a fork of Penguin designed to support saves created by Newer Super Mario Bros. Wii.

While they are pretty much identical formats, Newer replaces a few settings to store Hammer Suits, spent star coins, switch flags, and most notably,
it replaces the Hint Movie unlocks with the current world's map info. The original editor can save some of these correctly, however others will usually
get overwritten.

**Note:** While this tool can load/save the world info, it does not support editing it. You can change the world info using [Koopatlas](https://github.com/RoadrunnerWMC/Koopatlas-Updated).
